🌸 YOAJUNG (또는 프로젝트명)

📌 프로젝트 소개
커스터마이징 가능한 요거트 아이스크림 서비스 웹사이트

🎯 제작 목적
- 사용자가 직접 맛과 토핑을 선택하는 경험 제공
- 핑크 톤 감성적인 브랜드 아이덴티티 구현

🛠 사용 기술
- HTML5
- CSS3 (반응형 디자인)
- JavaScript (인터랙티브 효과)

✨ 주요 기능
- 제품 커스터마이징 인터페이스
- 반응형 레이아웃 (모바일/태블릿/데스크톱)
- 감성적인 UI/UX 디자인

💡 어려웠던 점과 해결
- 브랜드 감성을 웹에서 표현하는 것이 어려웠음
- 핑크 컬러 팔레트와 타이포그래피로 통일감 부여
